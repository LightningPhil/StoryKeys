# Historical Prototype Specifications (Archive)

The documents in `Initial docs/` are early design notes and single-file prototype specifications (`v1`–`v6`) created before StoryKeys moved to its current Vite + TypeScript + Tailwind v4 architecture (`v8`).

They are retained for historical context only. For current architecture, UI conventions, and verification scripts, see:

- `README.md` (repository root)
- `UI-INVENTORY.md` (screens, modals, colour tokens, and accessibility rules)
